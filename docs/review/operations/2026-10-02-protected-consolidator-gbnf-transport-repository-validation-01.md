## Trusted boundary retained

The integration does not replace semantic validation with grammar validation.

The following remain trusted-code responsibilities:

- decoded top-level/key-set validation;
- source-content SHA recomputation;
- summary constraints;
- confidence constraints;
- non-empty evidence requirement;
- exact source-excerpt substring binding;
- evidence canonicalization to `source_excerpt_hash`;
- secret-output filtering;
- fixed trust class;
- mandatory human review.

Therefore:

`GBNF = transport/syntax constraint`

and:

`validate_output() = semantic authority`
